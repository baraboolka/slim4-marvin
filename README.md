# Slim4-Marvin

Hello. This is a simple CRUD system, based on Slim 4

## System requirements

* Web server with URL rewriting
* PHP 7.4 or newer
* Mysql 5.6 or newer
* Personal сomputer

## Database

* The database-dump is in the root directory
* Filename: slim4-marvin-db.sql
* Don't forget to import the database and change the config file: config.php
